# Mobile questionnaire layout refinements

## Goal
Improve the phone layout while leaving the desktop experience unchanged.

## Changes

1. **Remove the top media banner from Steps 2–9 on mobile**
   - Hide the image/video side of the shared question layout below the desktop breakpoint.
   - Keep the existing media panel and interactions unchanged on desktop.
   - Retain the images displayed inside the individual option cards on mobile.
   - With the banner hidden, the question content will move directly beneath the header.

2. **Use two-column option grids on mobile for Steps 2, 4, 5, and 7**
   - Change the main option lists for Project Type, Role, Project Scale, and Project Lifecycle to two columns at phone widths, matching Step 6.
   - Keep Step 7’s separate Yes/No row in its existing two-column layout.
   - Preserve the existing desktop layout.

3. **Slightly reduce the Step 1 headline on mobile**
   - Reduce the mobile headline from 22px to 20px so the sentence occupies less vertical space.
   - Keep tablet and desktop headline sizes unchanged.

## Validation
- Check Steps 1–9 at the current 394 × 642 mobile viewport.
- Confirm Steps 2–9 have no top media banner, option-card images remain visible, and Steps 2, 4, 5, and 7 use two columns.
- Confirm desktop media panels and layouts remain unchanged.
